# מסלול · בונה אתרי טיול

אתר שבונה אתרי טיול. ממלאים יעד, הרכב נוסעים ומספר ימים — ומקבלים אתר מלא: מסלול לפי שעות, ניווט, יומן תמונות משותף, תרגום, המרת מטבע, מזג אוויר, ציוד, תקציב ומצב ילדים עם הקראה בקול.

---

## מה יש כאן

```
index.html                        האתר כולו — קובץ אחד
netlify.toml                      הגדרות פריסה
netlify/functions/generate.js     מתווך למודל השפה (המפתח יושב כאן, לא בדפדפן)
netlify/functions/config.js       מספק לדפדפן את פרטי הענן
supabase/supabase-setup.sql       הקמת מסד הנתונים
```

## דרך א׳ — העלאה ידנית (הכי מהיר)

גוררים את **כל התיקייה** לחלון של [app.netlify.com/drop](https://app.netlify.com/drop). זהו, האתר באוויר.

החיסרון: בכל שינוי צריך לגרור שוב.

## דרך ב׳ — גיטהאב עם פריסה אוטומטית (מומלץ)

מרגע שזה מוגדר, כל שינוי שתדחוף לגיטהאב יעלה לאתר תוך דקה, לבד.

**1. יוצרים ריפו**

ב-[github.com/new](https://github.com/new): שם, Private או Public, בלי README.

**2. מעלים את הקבצים**

הדרך הקלה: בעמוד הריפו החדש לוחצים **uploading an existing file** וגוררים את התוכן. שימו לב לגרור את הקבצים והתיקיות, לא את התיקייה החיצונית — `index.html` צריך להיות בשורש הריפו.

או מהטרמינל:

```bash
cd site
git init
git add .
git commit -m "מסלול · גרסה ראשונה"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

**3. מחברים לנטליפיי**

ב-Netlify: **Add new site → Import an existing project → GitHub**, בוחרים את הריפו.

בהגדרות הבנייה:

| שדה | ערך |
|---|---|
| Build command | להשאיר ריק |
| Publish directory | `.` |
| Functions directory | `netlify/functions` |

לוחצים Deploy.

**4. מוסיפים את המפתחות**

**Site configuration → Environment variables:**

| שם | ערך | חובה? |
|---|---|---|
| `GEMINI_API_KEY` | מפתח חינמי מ-[aistudio.google.com](https://aistudio.google.com/apikey) | אחד מהשניים |
| `ANTHROPIC_API_KEY` | מפתח מ-[console.anthropic.com](https://console.anthropic.com/settings/keys) | אחד מהשניים |
| `SUPABASE_URL` | `https://xxxx.supabase.co` | לשיתוף בין מכשירים |
| `SUPABASE_ANON_KEY` | המפתח **anon public** (לא service_role) | לשיתוף בין מכשירים |
| `DAILY_LIMIT_PER_IP` | ברירת מחדל 60 | לא |

אחרי הוספה: **Deploys → Trigger deploy → Deploy site**. משתני סביבה נכנסים לתוקף רק בפריסה חדשה.

**5. מקימים את מסד הנתונים**

בסופאבייס: **SQL Editor → New query**, מדביקים את `supabase/supabase-setup.sql`, לוחצים Run. בטוח להרצה חוזרת.

## מה קורה אם לא מגדירים כלום

האתר עובד. המשתמש מקבל מסך בחירה: מפתח חינמי מגוגל בשלושה צעדים מוסברים, או הדבקה דרך ChatGPT בלי שום הרשמה. היומן נשמר במכשיר שלו.

## עלות

- **גוגל** — חינם במסלול הבסיסי, עם מכסת בקשות לדקה.
- **אנתרופיק** — סנטים בודדים לטיול. כדאי להגדיר תקרת הוצאה חודשית בקונסולה.
- **סופאבייס** — חינם עד 1GB אחסון. יש מגבלה מובנית של 50 תמונות לטיול, כלומר כ-65 טיולים.
- **נטליפיי** — חינם לשימוש בהיקף הזה.

## אבטחה

מפתח ה-anon של סופאבייס נשלח לדפדפן ולכן הוא ציבורי מטבעו. לכן סקריפט ההקמה **נועל את הטבלאות**: אי אפשר לקרוא או לכתוב בהן ישירות, גם עם המפתח. הגישה היחידה היא דרך פונקציות שדורשות מזהה טיול מדויק, והמזהים אקראיים באורך 18 תווים. מי שיש לו קישור לטיול רואה את הטיול הזה בלבד.

מפתחות המודל לעולם לא מגיעים לדפדפן — הם יושבים במשתני הסביבה של נטליפיי בלבד.
